If an iPhone cannot connect to Wi-Fi, open Settings, Wi-Fi and check that Wi-Fi is on. A blue checkmark beside a network name indicates that the phone joined that network; it does not by itself prove that internet access works. Check that Airplane Mode is off. For a No Internet Connection message, try the same network on another device to see whether the problem is limited to the iPhone. If other devices also cannot get online, check the router or contact the internet service provider. Restarting the iPhone or router can help with some connection problems. Reset Network Settings removes saved Wi-Fi networks and passwords, so treat it as a later step and explain the consequence before suggesting it. A typed connection description alone cannot establish whether a network is safe or identify the cause of an outage.
